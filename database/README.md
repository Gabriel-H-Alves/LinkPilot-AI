# LinkPilot AI - Documentação de Banco de Dados

## Planejamento de Infraestrutura de Banco de Dados

O LinkPilot AI utilizará **PostgreSQL**, com a possibilidade de uso do **Supabase** como infraestrutura gerenciada na nuvem.

### Estrutura de Diretórios:
- `database/migrations/`: Contém os scripts SQL para criação e alteração de tabelas e esquemas.
- `database/seeds/`: Contém os scripts SQL ou dados para povoamento inicial de testes e desenvolvimento.

> **Nota:** As migrations e regras de negócio de banco de dados serão implementadas manualmente pelo desenvolvedor nas próximas etapas.

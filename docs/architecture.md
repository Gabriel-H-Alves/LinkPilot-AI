# LinkPilot AI - Documentação do Projeto

Este diretório contém a documentação técnica, decisões arquiteturais e guias operacionais do LinkPilot AI.

## Tópicos Planejados
- **Arquitetura de Agentes**: Detalhamento dos 5 agentes planejados (Research Agent, Content Strategist, Copywriter Agent, Quality Reviewer, Publishing Assistant).
- **Especificação da API REST**: Endpoints, schemas de requisição e resposta.
- **Modelagem de Dados**: Diagramas entidade-relacionamento e dicionário de dados.
- **Integração com Ollama**: Configuração de modelos LLM locais e endpoints de inferência.
